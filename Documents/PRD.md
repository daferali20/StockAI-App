# Product Requirements Document - StockAI

## المنتج
تطبيق تحليل أسهم باستخدام الذكاء الاصطناعي.

## الميزات الرئيسية
1. **تحليل الأسهم**: عرض بيانات مالية وتحليلات فنية
2. **توصيات ذكاء اصطناعي**: توقعات باستخدام Gemini AI
3. **متابعة المحفظة**: تتبع أداء الأسهم المفضلة
4. **تنبيهات**: إشعارات عند تغيرات الأسعار

## المستخدمون
- مستثمرون مبتدئون ومتوسطون
- متداولون يوميون

## متطلبات تقنية
- iOS 16.0+
- اتصال بالإنترنت
- مفاتيح API (Alpha Vantage, Gemini)

## جدول زمني
- MVP: 4 أسابيع
- الإصدار 1.0: 8 أسابيع
