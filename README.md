# StockAI-App

تطبيق ذكاء اصطناعي لتحليل الأسهم باستخدام SwiftUI وGemini AI.

## المتطلبات
- iOS 16.0+
- Xcode 15.0+
- Swift 5.9+

## التشغيل
1. نسخ المستودع: `git clone https://github.com/yourusername/StockAI-App.git`
2. تثبيت التبعيات: `cd StockAI-App && pod install`
3. فتح `StockAI.xcworkspace`
4. إضافة مفاتيح API في `Config.plist`
5. تشغيل التطبيق (⌘+R)

## الهيكل
- **StockAI/**: الكود المصدري للتطبيق
- **Backend/**: خادم وسيط (اختياري)
- **Documents/**: الوثائق والتصاميم
